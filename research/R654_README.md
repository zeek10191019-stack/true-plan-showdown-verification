# R654｜全81形態・画像クラス単位の誤認防止

## 目的
R595の生の特徴量候補の問題を軽減する。R595の旧結果は歴史的診断として保ち、別の`r654_megareference_class_safety`を1ボタンZIP内の`historical_visual_region_changes.json`へ追加する。

## 防止する事故
- 同一形態の画像を複数登録したときに「別形態の対照画像がある」と誤解すること。比較はspecies/formクラスの最良スコアで行う。
- メガリザードンX/Y、メガライチュウX/Y、メガアブソル/Z、メガガブリアス/Z、メガルカリオ/Zのバリエーション漏れ。各speciesの通常姿と現行81形態に該当する全Mega formを参照に要求する。
- 通常姿／Mega姿の片方しかないのに候補を出すこと。
- 背景や他種族が近似した際、判定が低マージンのまま通ること。
- 関連性のない撮影フレーム、偽のROI、未レビュー参照を現在の戦況に昇格させること。R595の元検査を通過した履歴フレームと参照だけを処理する。

## 認証と制約
これは**候補の拒否率改善**であり、実ゲームの認識精度が上がったことの証明ではない。ROIは未校正16×12輝度グリッドで、隠れたメガ進化演出や性別/色違い/カメラ角度への頑健性は未評価。`mega_confirmed`、`owner_certified`、`current_state_eligible`、`battle_advice_authorized`は常にfalse。実ゲームで正解ラベル付きの参照を収集しない限り、候補は常に保留され得る。

R653はファイルロールバックの責務、R654は判定クラスガードの責務で分離。GitHubのmain上では自動起動対象は今回のworkflow自身だけに限定。保存は独立ブランチ、mainへの自動マージはしない。
