## 2. 確認できた画像出典
PokéAPIの`generation-ix/champions`画像ディレクトリについて、ポケモンIDと実在するファイル名を照合した。各メガ形態について、正面／背面／正面色違い／背面色違いのアニメーションWebP、および通常／色違いメニューアイコンの6カテゴリが存在する。

- レギュレーション上の81メガ形態：81/81件が6カテゴリ対応（81×6＝486パス）。
- メガニャオニクスはオスID`10314`とメスID`10326`を区別：外観クラスは合計82、対応パスは82×6＝492。
- `female/10314.webp`のファイル存在も確認したが、**画素内容を調べていない**。意味を推測で確定しない。
- 通常フラエッテの単純なベースID`670`について、調べたChampionsディレクトリには6カテゴリのファイルがなかった。メガフラエッテID`10296`には存在するため、通常→メガの教師画像が揃ったとは言えない。

## 3. 実装・権利に関する厳密な区別
- 「画像パス存在」は「画像を実際にダウンロードした」「画素の中身をチェックした」「ゲーム画面から正確にメガ姿を読める」のいずれも証明しない。
- 一般公開の出典URLやGitHubコードのライセンスは、キャラクター画像のAI学習・アプリ同梱・第三者再配布に関する包括的な許可ではない。画像バイナリの公開リポジトリへの保存を行わない。
- 画像素材はレンダリング済みのアニメーションWebPだが、対戦画面に映る姿はカメラ・姿勢・照明・遮蔽・演出・圧縮で変化する。
- リザードンX/Y、ライチュウX/Y、アブソル/アブソルZ、ガブリアス/ガブリアスZ、ルカリオ/ルカリオZ、ニャオニクスの性別を別の画像認識候補として扱う。
- R594/R595/R650の姿照合は歴史フレームの候補提示であり、自他、種族、メガ使用、対戦アドバイスの確定認証ではない。

## 4. 再現テスト
`python3 r651_asset_guard.py` と `python3 r651_selftest.py` を同じディレクトリのJSON2ファイルとともに実行する。
- 台帳：81種、76元種族、82外観クラス、492メタデータパスを照合。
- 故意に形態ID・URL・メガ確定フラグなどを改ざんする18試験すべてが拒否される。
- **これは保存したメタデータのローカル整合検査**であり、GitHub上の画像ファイルを毎回再ダウンロードして認証するテストではない。
